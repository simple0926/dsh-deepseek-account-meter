# v1.0.0 — DeepSeek 余额与用量

首个公开版本：在 DeepSeek Harness 的输入框下方实时显示**账户余额**与**全账户 token 累计消耗**。

```
余额 ¥49.22  ·  累计 1.55B tokens
```

## 亮点

- **余额实时可见** —— 直接读 DeepSeek 账户服务，支持 ¥ / $ 多钱包与赠送余额，失败时明确显示不可用而不是 `0`。
- **token 总量零重扫** —— 复用 Harness 已有的 `tokenUsage` 投影（按会话折叠整份日志、带重试替换语义），
  启动对账一次后按投影变更增量更新，26 个会话的种子成本约 1.5 ms。
- **原生观感** —— 注册在 composer dock（自带 token 用量行旁边），只用主题 token 与 locale 服务，
  中英文界面自动跟随，深浅色主题都匹配。
- **只在本机出现** —— 数据经一条仅回环地址可访问的 Host 路由送达页面；插件不持有凭证、不写入新事件类型。

## 安装

```bash
git clone https://github.com/simple0926/dsh-deepseek-account-meter.git
```

在 DSH 对话中让 Agent 执行：

```text
plugin_manager  action: install_bundle
                target: /绝对路径/dsh-deepseek-account-meter
```

安装后刷新页面，打开任意会话即可看到。卸载：`plugin_manager remove_bundle @local/dsh-deepseek-account-meter`。

## 显示口径

- **余额**：来自 Platform 的 `GET /api/v0/users/get_user_summary`，成功结果缓存 60 秒，点击可强制刷新。
- **累计 token**：来自**本机**会话日志的 provider 上报用量，跨会话求和；重启不清零，重试与替换不会重复计数，
  fork 会话按 `isSeeded` 跳过。
- 与开放平台账单口径独立：不合并其它设备 / 实例的用量，缓存读取的计费折扣也不体现在 token 数上
  （实测 15.5 亿总量中约 15.3 亿是 cache read，悬停可看分项）。

## 已验证

- 路由：`GET`/`HEAD` 200，`POST` 405，未知路径 404，非回环 403，`?refresh=1` 确认绕过缓存。
- 页面注册：`conversation.composer.dock` 下 occupant `deepseek-account-meter`（order 2）为 active。
- Host 逻辑：8 项 stub 冒烟测试通过（happy path、绝对值增量替换、fork 排除、未登录、余额失败不为 0、
  回环/方法守卫、服务缺失降级、缓存与强制刷新）。
- 环境：macOS 桌面版 DSH `0.2.1-rc.5`，实测 29 个会话、1.55B tokens 的端到端展示。

## 已知限制

- composer dock 是会话作用域，欢迎页不显示。
- 远程隧道 / 非回环地址访问时显示「暂无数据」。
- 未提供跨实例合并、用量导出与历史趋势。
- 余额缓存 60 秒，毫秒级变化需要点击刷新。

- 验证于 DSH `0.2.1-rc.5`（macOS 桌面版）。
